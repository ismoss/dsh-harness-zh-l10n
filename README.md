# dsh-harness-zh-l10n

DeepSeek Harness (dsh) 界面中文汉化工具。**多版本通用**——只要 dsh 的英文源串没变，rc.6 / rc.7 / rc.8 / rc.9 … 都能直接套用，不受行号漂移影响。

把 dsh 的五模式描述、权限标签、命令描述和梁神模式描述翻成中文，让界面一眼能看懂每个功能是干什么的、怎么用。

## 汉化了什么

| 模块 | 效果 |
|---|---|
| **五模式描述** | 标准/PTC/极简/创造/梁神的按钮文案变成「一句话看懂特点 + 怎么用」的中文 |
| **权限标签** | Read Only→**只读** / Workspace Write→**工作区写入** / Full access→**完全访问** |
| **命令描述** | `/compact` `/export` `/feedback` `/goal` `/permission` `/plan` 的说明改成中文（命令名不变） |
| **梁神模式描述** | 梁神模式在模式选择器里的介绍改成中文；并同步其 preset 术语（`PTC Mode`→`Code Mode (PTC)`）与精简配置 |

## 为什么「多版本通用」

早期版本用的是 `diff -u` 上下文补丁。这种补丁靠「变更行 + 上下各 3 行上下文」定位落点——**即使英文单词一字未改，只要周围代码行一漂移（比如 rc.8 把函数整体下移了 126 行），`patch` 就会因上下文对不上而报 "does not apply"**。这正是「没换单词翻译却失效」的根因。

本仓库改用 **`apply.js` 字符串替换脚本**：

- 按**精确子串**把英文/旧中文串替换为中文，不依赖行号或上下文，天然跨版本。
- 插入类改动（权限中文映射）用**锚点后插入**，锚点是稳定函数签名。
- 所有操作**幂等**：已应用过的串不会再改；版本漂移导致串不存在时自动跳过并报警，不会硬失败。
- 每个被改文件先备份为 `*.l10n.bak`，可随时还原。

## 使用方法（30 秒）

1. 确认 dsh 已安装在默认位置 `C:\dsh`（或设置环境变量 `DSH_ROOT` 指向你的安装根）
2. 下载本仓库（含 `apply.js` + `apply.bat` + `patches/` 参考补丁）放在同一文件夹
3. 双击 `apply.bat`，或命令行 `node apply.js`
   - 想先看效果不改动文件：`node apply.js --dry-run`
4. 重启 dsh
5. 浏览器打开 `http://127.0.0.1:3080`，按 **Ctrl+Shift+R** 硬刷新

> ⚠️ 梁神插件（`@linxin666/dsh-liangshen`）装在 `~/.dsh/` 下，dsh 升级不会冲掉它；脚本会检测已汉化的部分并自动跳过，不影响其他汉化。

## 回退

每个被修改的文件旁边会生成 `*.l10n.bak`。要恢复英文，把对应 `.l10n.bak` 复制回原名即可；或直接重装对应 npm 包。

## 适配版本

- 工作方式：按英文字串定位，**只要源串未变就通用**（已实测 rc.6 / rc.8）
- 若某次大版本把英文字串本身也改了，脚本会跳过该项并提示，届时按 `regenerate-patches.js`（dev 仓库）重新对齐即可
